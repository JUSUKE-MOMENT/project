# Password Generator

Password Generator — учебный веб-проект на React и TypeScript для генерации случайных паролей с настраиваемыми параметрами.

## Возможности

- настройка длины пароля;
- использование букв, цифр и специальных символов;
- генерация случайного пароля;
- копирование пароля в буфер обмена.

## Технологии

- React
- TypeScript
- Vite
- CSS

## Что умеет продукт сейчас

**Password Generator** — учебное веб-приложение для генерации паролей. Согласно концепции проекта, пользователь должен иметь возможность выбирать длину пароля и набор символов (буквы, цифры, специальные символы), генерировать пароль и копировать его.

На текущем этапе лабораторной №3 описаны концепция, структура репозитория и процесс дальнейшей разработки. Статус фактической реализации каждой функции следует уточнять по текущему коду; это описание продукта не является отчётом о завершённых задачах лабораторной №4.
